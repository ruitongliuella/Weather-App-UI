# Apple Weather UI Clone

A recreation of Apple's Weather app interface built with **SwiftUI**. This project focuses on replicating the visual design and layout of the iOS Weather app, including current weather conditions, hourly forecasts, and a 10-day forecast.

## Features

- Recreated the Apple Weather interface with current temperature, weather conditions, and daily high/low temperatures.
- Built an **hourly forecast section** displaying weather icons and temperatures throughout the day.
- Implemented a **10-day weather forecast** with daily weather conditions and temperature ranges.
- Created reusable SwiftUI components (`HourlyRowView` and `WeeklyRowView`) to organize forecast information.
- Used custom data models (`Hour` and `Day`) to structure and display weather data.
- Applied SF Symbols, rounded containers, and custom colors to match the visual style of Apple's Weather app.

**Note:** This project is a static UI recreation using sample weather data. It does not retrieve real-time weather information.

## Technologies Used

- **Language:** Swift
- **Framework:** SwiftUI
- **IDE:** Xcode
- **Platform:** iOS
